VisionHardwareCheck · HardwareCheck-01 · Windows x64

1. 将物理鼠标接到 KMBox 的鼠标输入口，KMBox USB 输出接设备 A。KMBox 网口与设备 B 接同一个局域网。
2. 只在设备 B 解压 ZIP 并双击 VisionHardwareCheck.exe。Windows 10/11 自带 .NET Framework 4.x，无需额外安装。
3. 填入盒子屏幕上的 IPv4、命令端口和 8 位十六进制 MAC/UUID。本机监控 UDP 端口应单独设置，默认 12345。点「连接 KMBox」再点「开始监控」。若盒子应答但没有报文，核对 USB 接法和本机防火墙，仅为可信网络开放所选 UDP 端口。
4. 各做 10 轮：单按左键、单按右键、先左后右、先右后左。两键同时按住才应计一次，任一键释放时应立即退出。再按中键和两个侧键。长按静止几秒，记下固件是否仍周期上报。若停止上报，1.2 秒后状态显示未知，移动锁止。
5. 设备 A 停在普通桌面。轻动一下接在盒子上的物理鼠标，收到新报文后，在 B 逐一点击四个小幅位移按钮，观察 A 上的方向。每次只发一条位移指令。
6. 测试 F8 和窗口内「紧急停止」。在另一次测试中，保持双键按下并拔盒子网线，确认组合退出且移动锁止。接回后重新连接。监控过期或急停后，需要重新按下组合。
7. 点「导出日志」并回传，同时报告四个方向是否正确、实体鼠标是否受影响、静止长按是否持续上报。应用日志记录收到报文的时间，无法单独测出手指物理动作到界面的端到端延迟。

本包只包含 KMBox 硬件验收。双键组合只更新显示，任何位移都需要用户点击。
