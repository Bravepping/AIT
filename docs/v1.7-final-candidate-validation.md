# V1.7 Final 候选更新验收结果

冻结版 `v1.7.0-rc.3`，对比基线 `v1.7.0-rc.2`。

## Track ID 回放

对同一段 90 帧 NDI 实录使用相同的人工标注和控制配置。P 和 PD 均由 5 次 Track ID 重分配降到 0 次，每种策略均保留 27 帧候选和 7 次可见期间的候选中断。控制等待保持 160 ms，旧身份最多保留 320 ms。先匹配连续可见目标，再接受双方最优且差距明确的预测关联。

既有素材覆盖一个画面对象的移动与重现。跨目标争用、错误类别和超窗重关联已通过模拟测试。真实多目标交叉、遮挡后身份恢复和多类别优先级仍待实录验收。[逐帧标注和对比数据](v1.7-tracking-regression.json)

## 控制安全

14 项 Rust 测试和 KMBox 本机模拟回环通过。覆盖过期帧和待发命令拒绝、按键报文过期、左右键任一释放、F8 后端停止、失去目标、断流、断连及恢复后重新武装。

NDI 帧龄阈值为 150 ms。本机模拟暂停源时在 169 ms 锁止，SDK 约 802 ms 收到断流通知。候选已清空，恢复后须手动重新武装。验收期间没有发送实体鼠标移动、点击或拖动。

## 安装与配置

Windows x64 候选包通过隔离安装、全新 WebView 用户目录启动、离线回放和卸载。验证环境使用 NDI Runtime 6.3.2.0、WebView2 158.0.4370.33 和 TensorRT 10.16.1.11。TensorRT 实际加载使用 FP16 mixed 并命中缓存。全新 Windows 的第三方依赖安装仍待验证。

V1.5 校准几何和轴向参数、V1.6 PD 与动态范围、V1.7 JSON 备份和恢复均通过代表性配置样本检查。候选包带有独立单步校准工具。[安装与现场操作说明](../apps/vision-studio/README.md)
